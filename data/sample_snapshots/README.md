# Sample Snapshot Policy

No private or raw broker data is committed here. The notebooks use deterministic synthetic option chains generated by `src/data/synthetic.py`.

If a sanitized local snapshot is added later, it must:

- contain no account identifiers, tokens, API keys, or private broker fields;
- pass `validate_option_schema`;
- include `source` and `is_synthetic` or equivalent provenance fields;
- remain small enough for a public GitHub repository.
